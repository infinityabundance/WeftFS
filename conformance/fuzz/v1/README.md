# Differential fuzz corpus (v1)

`seeds.txt` contains one lowercase-hex WFT1 frame per line: 44 valid seeds that
decode through `weftcodec::modes::decode_bytes` (Rust) and `modes.DecodeBytes`
(Go) with default limits.

Modes represented: RAW (plain and chunked), ZSTD (plain and chunked),
REFERENCE, DELTA, DICTIONARY, STRUCTURED, TENSOR, TOKEN_SEQUENCE,
QUANTIZED_TENSOR.

## Fixed dependency bases

Seeds that use REFERENCE, DELTA, or DICTIONARY reference exactly these bases,
which both fuzz runners preload into their in-memory resolver:

| Name | Exact bytes |
|---|---|
| `BASE0` | `0x00, 0x01, ..., 0xff` (256 bytes) |
| `BASE1` | ASCII `weftcodec fuzz base payload one\n` repeated 8 times (256 bytes) |
| `BASE2` | empty |
| `BASE3` | ASCII `delta-base-A` repeated 20 times (240 bytes) |

## Regenerating

The corpus is generated by `WeftCodec/examples/gen_fuzz_seeds.rs`, which
decodes every frame before emitting it:

```sh
scripts/docker-court.sh rust \
  "cd /work/WeftCodec && cargo run --release --quiet --example gen_fuzz_seeds \
     > /work/.docker-cache/fuzz/seeds.txt"
cp .docker-cache/fuzz/seeds.txt conformance/fuzz/v1/seeds.txt
```

## Running the differential court

```sh
scripts/fuzz-diff.sh          # N = 1,000,000
scripts/fuzz-diff.sh 1000000  # explicit
```

## Deterministic split (N = 1,000,000)

| Selector (`below(8)`) | Share | Input |
|---|---:|---|
| 0 | 1/8 | raw random bytes, length 0–2048 |
| 1 | 1/8 | un-repaired seed mutation (1–8 legacy operations) |
| 2–5 | 4/8 | repaired body/table mutation (1–4 operations), header and trailer CRC32C recomputed |
| 6 | 1/8 | semantic fault: missing/lying/denying dependency, self-cycle REFERENCE via DAG, wrong mode byte, `decoded_len = u64::MAX`, bad chunk extent, wrong content hash, unknown critical flag, non-canonical STRUCTURED body |
| 7 | 1/8 | clean seed (successful-decode / content-root path) |

The generator, corpus hash framing, and per-input line format are documented
verbatim in both runners:

- `WeftCodec/examples/fuzz_differential.rs`
- `WeftCodec-Go/cmd/fuzzdiff/main.go`

This is deterministic, synthetic, CPU-only differential testing. It is not
coverage-guided fuzzing.
