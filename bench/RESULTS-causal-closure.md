# P02 — causal closure as a reproducible contract

**Date:** 2026-11-15. **Court:** `bench/scripts/causal_closure_court.sh` (bench
court, default limits) plus `scripts/training_artifact_court.sh` for the
artifact-backed refusal bundle. **Receipts:**
`bench/receipts/causal-closure-20261115T140739Z.json`,
`causal-closure-small-20261115T140739Z.json`, and the verifier blocks inside
them. **Normative:** `spec/WEFT-CAUSAL.md` §4 and
`spec/WEFT-TRAINING-ARTIFACT.md` §5.

## 1. Definitions

Nodes are artifact identities. Edges are a node's stored
`weft.causal.parents`. The stored `weft.causal.closure` array is a *declared
transitive set*, not an edge list.

* **complete** follows `parents` ∪ declared `closure`; it is the union of every
  declared ancestor reachable from the requested roots.
* **minimal** follows `parents` edges only, from the roots the request actually
  needs: for a Training Artifact, the artifact's own direct parents plus the
  member objects it must read. Provenance receipt ids are not graph nodes.
  Member objects' unrelated causal ancestry is excluded.

Both are bounded by `max_depth` (edge hops; a root is depth 0) and `max_nodes`.
Both return nodes in strictly ascending identity order; depth is reported but
never used to order. `total_closure_size` and `returned_closure_size` are
reported separately and v1 `truncated` is always false: a budget is a refusal,
not a truncation.

## 2. Refusal semantics

A referenced identity that is absent, or that the principal may not see,
produces the same `DependencyMismatch` and the same text. The text names the
identity the caller already supplied (and the subject that declared it),
so a missing dependency is actionable without disclosing that a hidden one
exists. Depth or node bounds produce `LimitExceeded` naming the boundary. A
canonical array violation is `NonCanonical`. The producer never returns a
closure that silently omits a declared ancestor.

## 4. Independent verifier

`verifier/closure_check.py` (Python stdlib plus the repository's independent
BLAKE3/WCB reader; no WeftFS import, no FFI, no subprocess) takes a
`weft.closure.bundle.v1` JSON bundle containing the canonical
`weft.causal.v1` bytes for every node. It:

1. decodes each record and requires the exact key set and schema;
2. requires arrays strictly ascending, unique, nonzero, and `closure ⊇ parents`;
3. recomputes `H("weft/causal/v1", record_bytes)` and compares the declared id;
4. recomputes complete or minimal closure from edges alone, including depth and
   node bounds, and compares the node set, order and depths;
5. for a refusal bundle, recomputes the same refusal class and requires the
   message to name the same missing identity.

The bundle is generated by Rust for the Training Artifact and by the benchmark
harness for the synthetic graph. The rules that were not in the specification
and had to be learned from the implementation are recorded in
[`docs/CAUSAL-CLOSURE-FINDINGS.md`](../docs/CAUSAL-CLOSURE-FINDINGS.md).

## 5. Losses

* **Minimal is barely cheaper here.** On the main fixture minimal excludes only
  the declared side chain but keeps the shared trunk; the node and time
  difference is in the table above and is small relative to the trunk. The
  closure definition does not make a wide graph cheap; the graph shape does.
* **One-shot queries do not amortise the index.** The indexed one-shot total is
  dominated by the graph build and is statistically indistinguishable from the
  naive scan (single-query numbers above). The index pays only on repeated
  queries.
* **The default depth bound refuses deep chains.** A deep-chain fixture was
  refused `LimitExceeded` at the default depth bound. That is correct behaviour,
  and it means the default cannot resolve a very deep iterative-training
  lineage without an explicit larger bound.
* **Whole-state indexing.** `CausalGraph::build` scans every object and decodes
  every causal attribute set: O(state), not O(reachable closure). Incremental
  index maintenance is not implemented.
* **Identity kind.** The graph is indexed by `VersionId`. A closure entry that
  names an `ObjectId`, `ContentId` or `CausalClosureId` (legal as a causal
  identity) does not resolve as a graph node and is refused. The fixture only
  uses version identities.
* **No authorization filtering in the CLI.** `compute` takes a `visible`
  predicate and the unit test proves absent/denied are indistinguishable, but
  the CLI path passes an all-visible predicate; a capability-filtered closure
  query is not exposed.
* **Verifier scope.** It checks the closure from records, not that the records
  are authorized or that the producer's node set is complete for a request it
  cannot see.

## 6. Non-claims

No cross-store or cross-organization causality. No cryptographic proof of
ancestry: the hash binds the record, and the truth is checked at resolution.
No claim that minimal is sufficient for training continuation; it is sufficient
for the declared verification request only. One host, warm cache, synthetic
graph. The timing numbers are host measurements with a fixed repetition count,
not a hardware-independent bound.
